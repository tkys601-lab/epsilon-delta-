ε-δ論法のしくみ

「x を a に近づけると f(x) は L に近づく」を、不等式だけで正確に言い直す方法。図を動かしながら読んでください。

1定義

limx→a f(x) = L

とは、どんなに小さい ε > 0 を指定されても、ある δ > 0 を選べば、0 < |x − a| < δ を満たすすべての x で |f(x) − L| < ε が成り立つ、ということ。

ε（イプシロン）＝ 許す誤差f(x) が L からどれだけずれてよいか。グラフでは縦方向の幅。
δ（デルタ）＝ 近さの目安x を a にどこまで近づければよいか。グラフでは横方向の幅。

2挑戦者と回答者のゲーム

定義は、2 人のやりとりとして読むと分かりやすくなります。

  1. 挑戦者が「誤差を ε = 0.01 以内にしてみせて」と注文する。
  2. 回答者が「x を a から δ = 0.002 以内に取れば大丈夫」と答える。
  3. 挑戦者が ε をどこまで小さくしても回答者が必ず δ を返せるなら、極限は L。

順番が大事。ε が先、δ が後。δ は ε を見てから決めてよい。

3図で確かめる：x² → 4（x → 2）

緑の横帯が L ± ε、紫の縦帯が a ± δ。縦帯の中のグラフ（太線）がすべて横帯に収まれば成功です。

2.0 0.80

おすすめの操作順

  1. 最初の状態（ε = 2.0, δ = 0.8）は失敗。x の範囲が広すぎてグラフがはみ出す。
  2. δ を小さくすると、どこかで成功に変わる。
  3. ε を 0.5、0.1 と厳しくすると、また失敗する。
  4. 「δ を自動で選ぶ」を押すと、もっと小さい δ でまた成功できる。
    → どんな ε にも δ で応えられる ＝ 極限は 4。
  5. 目標を L = 4.5 にして ε を 0.5 未満にすると、どんな δ でも成功しない。これが「極限は 4.5 ではない」ということ。

白丸の点 (2, 4) そのものは判定に使いません。定義の 0 < |x − a| は「x = a は除く」という意味で、f(a) が定義されていなくても極限は考えられます。

4証明の書き方（例題）

limx→2 (3x + 1) = 7 を示す。

下書き：結論から逆算して δ を探す

|f(x) − 7| = |3x − 6| = 3|x − 2|。これを ε 未満にしたいので、|x − 2| < ε/3 であればよい。

清書：δ を先に宣言する

任意の ε > 0 に対し δ = ε/3 とおく。0 < |x − 2| < δ ならば
|(3x + 1) − 7| = 3|x − 2| < 3δ = ε。　∎

曲線のとき：x² → 4

|x² − 4| = |x − 2|·|x + 2|。|x + 2| が残るので、まず δ ≤ 1 と決めておく。すると 1 < x < 3 なので |x + 2| < 5、よって |x² − 4| < 5|x − 2|。
したがって δ = min(1, ε/5) とすればよい。

5よくあるまちがい

ε と δ の順番を逆にする
「ある δ に対してすべての ε で…」では別の意味（しかも、ほぼ成り立たない主張）になる。
x = a での値を見てしまう
極限は「a のまわり」の話。f(a) の値も、定義されているかどうかも関係ない。
いちばん大きい δ を探そうとする
δ は 1 つ見つかれば十分。小さめに取って構わない。

6練習問題

問 1　limx→1 (2x − 5) = −3 を ε-δ で示せ。
|(2x − 5) − (−3)| = 2|x − 1|。δ = ε/2 とおけば、0 < |x − 1| < δ のとき 2|x − 1| < 2δ = ε。
問 2　limx→3 x² = 9 を示せ。
|x² − 9| = |x − 3|·|x + 3|。δ ≤ 1 なら 2 < x < 4 で |x + 3| < 7。δ = min(1, ε/7) とおけば |x² − 9| < 7δ ≤ ε。
問 3　上の図で L = 4.5 のとき、ε = 0.3 に対して成功する δ がないのはなぜか。
x を 2 に近づけると x² は 4 に近づくので、どんな小さい δ を取っても縦帯の中には x² ≒ 4 の点がある。|4 − 4.5| = 0.5 > 0.3 なので、その点は横帯（4.2〜4.8）に入らない。

7何の役に立つのか

「当たり前」を証明できるようにする

微分の定義 f′(a) = lim (f(a+h) − f(a))/h の lim は ε-δ そのもの。中間値の定理（連続なら途中の値を必ず通る＝二分法の根拠）や、積分の定義もこの上に立っています。

直感が外れる場面を見分ける

xⁿ（0 ≤ x ≤ 1）は n → ∞ で x = 1 だけ値が飛ぶ。フーリエ級数の角に残る約 9 % のはみ出し（ギブス現象）。極限と積分の順番を入れ替えてよいか。こうした判断は ε-δ（ε-N）の言葉でしかできません。

工学の「許容誤差」と同じ形

ε ＝ 出力の許容誤差「位置決め誤差を 1 nm 以内に」
δ ＝ 入力をどこまで抑えるか「では DAC の誤差を ○ mV 以内に」

どんな ε にも δ がある（＝連続）なら、入力側を良くすれば必ず精度は出せる。δ が見つからないなら、出力が飛んでいる（不連続・飽和・ヒステリシス）。制御の安定性（リアプノフ安定）の定義も、この ε-δ の形をしています。

数列の ε-N論法も同じ考え方です：「どんな ε にも、ある番号 N から先はすべて誤差 ε 以内」。
